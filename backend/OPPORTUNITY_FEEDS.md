# Opportunity discovery and source integration

`GET /api/v1/opportunities` ranks published, current listings against the signed-in student's persisted interests, skills, and custom goal. Each card includes `matchScore` and `matchedSignals`. The score orders cards; it does not assert eligibility. If Christa's profile port is not connected yet, the endpoint falls back to newest-first ordering. Only the 1,000 most recently reviewed eligible listings enter the ranking pool.

The existing `SAMVED_OPPORTUNITY_IMPORT` path remains available for human-reviewed JSON files. An optional Java scheduler can poll **approved JSON feeds** every six hours. Set `SAMVED_OPPORTUNITY_FEED_URLS` to a comma-separated list of at most five direct HTTPS URLs. Each response must be `application/json`, at most 1 MB, and contain at most 500 `OpportunityImporter.Draft` objects. Redirects are not followed. The normal validation and source-URL upsert rules still apply. Do not configure an arbitrary webpage, undocumented internal API, or a feed without permission to reuse its listing data. Feed failures are logged and keep the prior database contents.

Unstop discovery now has a separate Java importer for its public `/api/public/opportunity/search-result` endpoint. Set `SAMVED_UNSTOP_ENABLED=true` in the ignored `backend/.env` to enable it locally. It refreshes every six hours, one page of 20 items per category by default. The supported categories are jobs, internships, hackathons, competitions, quizzes, scholarships, and workshops. `SAMVED_UNSTOP_PAGES` may be 1–3 and `SAMVED_UNSTOP_PAGE_SIZE` may be 1–50; those bounds prevent an unbounded crawl. The importer only keeps currently open, live records, validates the source path, and saves the title, organizer, skills, location, registration deadline if supplied, and original Unstop link. The full listing remains on Unstop. Missing registration deadlines remain unknown. A refresh failure leaves prior rows in place; the normal 30-day review window and known deadline hide stale rows from the active feed. If Unstop changes or blocks this undocumented endpoint, the logs show the failure. Stop using it if Unstop's access rules change.

There are no authorized automatic feeds configured for HackCulture or Devfolio. Use a partner feed/API agreement or the reviewed import flow for those sources.

Google search results are **not** ingested into SAMVED. Google's Custom Search JSON API is closed to new customers, so there is no free new-account server-side Google feed to configure here. A free ad-supported Programmable Search Element can display Google results in a browser after the team creates a search engine, but those results are not SAMVED records and cannot supply verified deadlines or relevance scores. Do not scrape Google result pages into the database.

Before enabling automatic publication, obtain feed permission and confirm source attribution, update frequency, expiry behavior, content license, and whether eligibility and deadlines are included. A feed without dates may be shown with an unknown deadline; it must not be labeled as definitely open. The import validator rejects stale `verifiedAt` values for published records.
